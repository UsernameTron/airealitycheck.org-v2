Adding More Videos — scaffold reference
To add a new video to this page:
  1. Get the YouTube video ID (the string after youtu.be/ in the share URL).
  2. In this file's source, find the comment block labeled TEMPLATE — VIDEO CARD.
  3. Copy any existing <a class="video-card"> block and paste it next to the others.
  4. Replace the video ID in 3 places: the href, the img src (maxresdefault), and the img onerror src (hqdefault fallback).
  5. Update the vtitle with the actual video title and the vdesc with a one-line description.
  6. Commit and push. Thumbnails are pulled live from YouTube — no image upload needed.
